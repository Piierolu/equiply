# Equiply frontend

Next.js App Router frontend for the Equiply operations workspace. It uses TypeScript, Tailwind CSS, and shadcn/ui.

Set `NEXT_PUBLIC_SITE_URL` to the public origin in production so canonical URLs, structured data, and the sitemap use the deployed domain.

## Development

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Use `npm run lint`, `npm run typecheck`, and `npm run build` before opening a pull request. The repository root README contains the full-stack setup.
