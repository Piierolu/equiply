# Delivery roadmap

The items below are intended to become GitHub issues and small pull requests as the product evolves. They are not a substitute for actual repository history.

1. Reservation availability rules and conflict tests.
2. Quotes and reservation confirmation.
3. Equipment allocation and preparation workflow.
4. Dispatch, partial return, late return, and damage handling.
5. Playwright coverage for login, inventory CRUD, and tenant isolation.
6. Public demo deployment and README screenshots.

Organization invitations, branch transfers, Stripe, Kafka, S3, and email notifications are optional extensions. They should only be added if the portfolio needs to demonstrate those integrations explicitly.
